# Gen AI for Modern Workforce — Prompt Lib

## Local preview

```bash
cd personal-os/agent-course-writer/courses/genai-for-manager-2026/genai4mf-prompt-lib-main
mkdocs serve
```

Open http://127.0.0.1:8000 in your browser. Changes to `docs/` reload automatically.

## Publish to GitHub Pages

```bash
mkdocs gh-deploy
```

This builds the site and pushes it to the `gh-pages` branch. Live at:
https://warasinee-cha.github.io/genai4mf-prompt-lib/

## Install MkDocs (first time only)

```bash
pip install mkdocs-material
```
