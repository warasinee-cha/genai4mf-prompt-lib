# Web Application

สร้าง Prototype แอปพลิเคชัน **RM Insight Pro** ด้วย **Google AI Studio** ภายใน 30 วินาที ใช้ในการสอน Executive ของ SCB ให้เห็นว่า AI สามารถช่วย Prototype ไอเดียนวัตกรรมได้รวดเร็วแค่ไหน

แอปนี้จินตนาการว่าจะช่วย Relationship Manager ของธนาคารบริหารลูกค้าองค์กรได้ดีขึ้น ด้วยการวิเคราะห์ข้อมูลและแนะนำโอกาสทางธุรกิจแบบ Real-time
